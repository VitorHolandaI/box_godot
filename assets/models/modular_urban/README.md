# Modular Urban Kit (Kenney Retro Urban - CC0)

Pecas modulares 3D de 1.0m x 1.0m para construcao procedural de predios:
- `wall-a.glb`, `wall-b.glb`: Paredes solidas.
- `wall-*-door.glb`: Paredes com portas de entrada.
- `wall-*-window.glb`: Paredes com janelas.
- `wall-*-corner.glb`: Pecas de quina.
- `wall-*-roof.glb`, `wall-*-roof-slant.glb`: Pecas de telhado e cumeeira.
- `wall-*-garage.glb`: Portas de garagem.
- `balcony-*.glb`: Sacadas e escadas de incendio.
- Acessorios urbanos: barreiras, pallets, dumpsters, luzes.
