# Generators

Os geradores recebem seeds e retornam somente blueprints. Eles nao criam nodes,
meshes ou colisoes.

- `room_generator.gd`: layouts de apartamentos e lobby.
- `building_generator.gd`: arquétipos de casas e predios residenciais.
- `city_generator.gd`: ruas, quarteiroes, lotes e selecao de edificios.
